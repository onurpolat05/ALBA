# bash-validator regression cases - run by tools/test-validator.sh (and doctor.sh).
# Format: <expected>|<command>   expected = deny | none
# "none" means no output: the normal permission flow applies. The validator never
# returns "allow", so a "none" is a prompt, not an auto-run.
# <NL> stands for a newline inside the command.
#
# Inherent gaps (documented, deliberately NOT asserted): bash -c "...", eval,
# base64 -d | sh, python3 -c, find / -delete, xargs rm, git clean -fdx,
# git reset --hard. A blocklist cannot enumerate every spelling.
